RUNANYWHERE SWIFT SDK: CURRENT PUBLIC API CATALOG
================================================

Repository: RunanywhereAI/runanywhere-sdks
SDK: sdk/runanywhere-swift
Branch: siddhesh/flutter-sdk-testing
Commit: 2ea354745be18bf691552b0d2a98236c57d56d28

Purpose
-------
This file records the current API before any rename or merge work.

Each entry contains:

  Name        Current Swift API name
  Arguments   Current argument labels, types, and defaults
  Returns     Current return type
  Does        The work performed by the API

Scope
-----
The main list covers application-facing operations reached through
RunAnywhere.* and its public capability namespaces.

The appendices cover related stateful public types such as EventBus,
HybridSTTRouter, and SolutionHandle.

The catalog excludes:

  - generated protobuf support methods
  - CppBridge transport methods
  - private helpers
  - protocol-conformance methods such as encode(to:)
  - tests and example-app functions

implementation or advanced infrastructure rather than the application SDK
