This is the hand-written Swift-facing API surface. It includes functions
declared explicitly public and functions inside public extensions. It excludes:

- generated protobuf implementation methods
- internal C/C++ bridge functions
- tests and example-app helpers
- public properties and initializers (this is a function list)

The Kotlin, Flutter, and React Native SDKs implement largely the same capability
groups, but their function signatures and platform helpers are not identical.

NOTES
-----

1. Swift is the reference/canonical surface for parts of the cross-SDK API,
   but the other SDKs use their own language conventions:

   - Kotlin: suspend functions, Flow, ByteArray, Android Context/Bitmap
   - Flutter: Future/Stream and capability objects such as RunAnywhere.llm
   - React Native: Promise/AsyncIterable and TypeScript/proto-ts types

2. Lower-level CppBridge namespaces are intentionally excluded even where an
   implementation declaration is marked public. They are transport plumbing
   behind the supported RunAnywhere facade, not the application-facing API.

3. A compiler-generated symbol graph was attempted, but this checkout's local
   RACommons/RABackend XCFramework directories do not contain usable binary
   artifacts. Therefore this inventory was verified from the hand-written
   source declarations rather than a successfully built symbol graph.
